プライバシーポリシー（AX Gmail Ops）

制定日：2026年11月20日

1. このツールについて

AX Gmail Ops（以下「本ツール」）は、運営者である今西 勇哉 が、自分の Google アカウントのデータを整理するためだけに使う本人専用のツールです。運営者以外の方の利用は想定していません。

2. 取得するデータ

本ツールは、運営者が許可した Google アカウントについて、次のデータにアクセスします。

  • Gmail：メールの本文・件名・送信者・ラベル、フィルタと転送の設定
  • Google カレンダー：予定（読み取りのみ）
  • Google Tasks：タスクの一覧と内容

3. 使い方

取得したデータは、運営者自身の業務の整理（メールの仕分け、領収書の保存、予定とタスクの管理）にだけ使います。

データは運営者のパソコンの上で処理します。処理の一部で、運営者が使う AI アシスタント（Anthropic 社の Claude）にデータを渡すことがあります。

4. 第三者への提供

取得したデータを販売したり、広告に使ったり、第三者に提供したりしません。法令に基づく場合を除きます。

5. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の利用と他のアプリへの移転は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。Google ユーザーデータを、汎用の AI・機械学習モデルの開発・改善・学習に使うことはしません。

6. 保存と削除

アクセスのための鍵は、運営者のパスワード管理ツールに保存します。Google アカウントのアクセス権の管理 から、いつでも本ツールの許可を取り消せます。
